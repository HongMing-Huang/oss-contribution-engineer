# dev/ — Experiment & Design History (not part of the Skill)

The shippable Skill lives in [`../oss-contribution-engineer/`](../oss-contribution-engineer/).
Everything in `dev/` is experiment history, design notes, and acceptance
evidence. It is **not** loaded by the Skill and carries no maturity meaning —
see the maturity ladder in the [Skill README](../oss-contribution-engineer/README.md).

## Layout

| Path | What it is |
|---|---|
| `v3/` | V3 design + research corpus (13-system comparative matrix, paper synthesis, retrieval architecture). `v3/research/README-HISTORICAL.md` marks it historical. |
| `v8/` | V8 real-repository benchmark round: frozen tasks, 4-arm bench runner, profiler, experiment ledger (failure records F1–F8), acceptance transcripts. |
| `v9/` | V9 blind-task validity round: verbatim-source task freeze + leak check, equal-unit bench, Serena/LSP real-backend runs, per-stage latency profile. |
| `v10/` | V10 skill-integration acceptance: session-ops-only real-task runs (click PATCH_READY, requests PATCH_READY), transcripts, manifests, F4/F6 closure evidence. |
| `eval/` | Early evaluation fixtures (upstream PR-state captures) and scenario definitions used by `tests/`. |
| `example-runs/` | Early manual example runs (click triage → NO_PATCH, fd → CONFIRMED). |
| `runs/` | Integration-run reports from earlier rounds (V6 backends). |
| `design.md`, `research-notes.md`, `evaluation-report.md`, `goal-*.md`, `validation-results.md` | Design and validation documents from the early goal iterations (V2–V4 era). |

## Rules

- Ledgers are **append-only**: old results are never rewritten; new rounds append.
- Anything regenerated by tooling (clones, venvs, language servers, scanner
  caches) is git-ignored and deleted after runs.
- Version labels (V8/V9/V10) are experiment-history only. Maturity is tracked
  separately in [`CAPABILITIES.json`](../oss-contribution-engineer/CAPABILITIES.json).
